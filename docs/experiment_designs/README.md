# Experiment designs

Each design follows the same order:

1. Steering goal.
2. Base dataset used to build and select controllers.
3. In-distribution evaluation.
4. Transfer and capability evaluations using the same frozen controllers.
5. Models, methods, and measures.
6. The main comparison the experiment is meant to support.
