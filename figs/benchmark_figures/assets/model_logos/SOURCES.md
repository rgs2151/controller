# Model logo sources

- `gemma.png`: official Gemma mark from Google AI for Developers,
  <https://ai.google.dev/gemma/images/gemma_sq.png>.
- `llama.png`: official Meta Llama GitHub organization avatar,
  <https://avatars.githubusercontent.com/u/153379578?s=400&v=4>.

- `gemma.svg`: Gemma vector mark from the MIT-licensed Lobe Icons collection,
  <https://unpkg.com/@lobehub/icons-static-svg@latest/icons/gemma-color.svg>.
- `llama.svg`: Meta vector mark from the MIT-licensed Lobe Icons collection,
  <https://unpkg.com/@lobehub/icons-static-svg@latest/icons/meta-color.svg>.
- `gemma_hq.png` and `llama_hq.png`: 1600-by-1600 transparent PNG renders
  generated locally from the corresponding SVG files for reliable embedding
  in Matplotlib PDF output. The source collection is available at
  <https://github.com/lobehub/lobe-icons>.

The marks are reproduced without recoloring. They are used only to identify
the evaluated foundation-model families in an academic figure.
